## 1. O problema

Antes de qualquer ferramenta, existe um problema. Escreva-o em prosa, com
**negrito** para o que importa, *itálico* para ênfase leve e `código` para
nomes técnicos como `PATH` ou `node_modules`.

> Uma citação vira uma caixa com filete lateral. Use para definições formais
> e para avisos que o leitor não pode pular.

## 2. A ideia central

Os três pontos que sustentam o resto do curso:

- **Primeiro ponto** — explicado numa linha só.
- **Segundo ponto** — que pode continuar na linha de baixo, desde que
  indentado, e o conversor junta tudo num parágrafo só.
- **Terceiro ponto**, com sub-itens:
  - um detalhe
  - outro detalhe

## 3. Um exemplo executável

```bash
# Comentário dentro do bloco de código
echo "Olá, livro!" | tr 'a-z' 'A-Z'
```

O rótulo `bash` aparece como etiqueta em cima da caixa.
